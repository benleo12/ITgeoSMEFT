# ITgeoSMEFT

Code and data for *Information Geometry for the Standard Model Effective
Field Theory* (Assi, Helset, Martin). Every number, table, and figure in the
paper is generated by a script in this repository.

## What the paper does

A SMEFT fit has more Wilson coefficients than the data can resolve. This
pipeline makes model reduction honest, in three steps:

1. **Exact relations** — coefficient combinations that change no prediction
   are found by one SVD of the stacked linear + quadratic response and are
   imposed at zero cost (Drell-Yan: `C_HB = C_HW`).
2. **A price for every drop** — the largest chi^2 change the drop can cause
   anywhere in the EFT validity box (worst case, priced jointly for sets).
   Drell-Yan with the measured CMS covariance: 19 coefficients -> 13 kept at
   a worst-case cost of 0.8 sigma.
3. **The twist certificate `kappa`** — decides whether the combination the
   data cannot see is the same everywhere (one relation removes it; LEP,
   kappa = 0.53) or rotates across the box (only drops are honest;
   Drell-Yan, kappa = 5.65, 47 degrees of rotation).

## Layout

```
core/     smeftgeo.py      loaders, Fisher metric, kernel, twist, MBAM ride
          battery_lib.py   whitening, monotone Gauss-Newton projection,
                           E_inf prices, kappa on the resolved slice
          pubstyle.py      shared figure style + Warsaw-basis name map
paper/    pub_figs.py            all 7 paper figures (pub_*.pdf)
          dy_reduce_realcov.py   DY drop-price ladder + greedy 19->13 (Table: ladder)
          dy_reduce_end2end.py   same with Poisson errors (comparison column)
          aic_contrast.py        AIC vs worst-case price (Table: AIC)
          lep_gates_verify.py    LEP kernel relations + price vs Lambda
          lep_curved_v3.py       LEP linear vs quadratic 68% intervals (Table: intervals)
checks/   cross-checks quoted in the text: monomial-SVD comparison,
          sub-block relation scan, real-covariance robustness, dim-8
          nuisance gate, noise robustness, twist-threshold calibration,
          when-kappa-fires demos, price-formula pseudodata closure
data/     dy_real_95_600.json    SMEFT Drell-Yan predictions, 101 bins,
                                 95-600 GeV, 19 coefficients (A, Hessian H)
          lep_real.json          LEP EWPO predictions, 11 observables,
                                 10 coefficients (A, Q)
          lep_rho.npy            LEP EWWG 11x11 correlation matrix
          cms_cov.npy, meas.json CMS Drell-Yan covariance + measurement
          dy_dim8.json           NDA-sized dimension-8 columns (nuisance gate)
          exporters/             Mathematica scripts that produced the json
figures/  the shipped pub_*.pdf / .png
```

## Data provenance

- **CMS Drell-Yan covariance and measurement**: CMS 13 TeV differential
  Drell-Yan, arXiv:1812.10529, from the HEPData record
  [doi:10.17182/hepdata.88043](https://www.hepdata.net/record/ins1711625)
  (Table 7 = measurement, Table 10 = combined covariance).
- **LEP EWPO correlations**: LEP Electroweak Working Group,
  arXiv:hep-ex/0509008.
- **SMEFT predictions** (`dy_real_95_600.json`, `lep_real.json`): exported
  from A. Martin's analysis notebooks by the scripts in `data/exporters/`.

## Conventions (important)

- Predictions are exactly quadratic:
  `mu_b(c) = SM_b + A_b . c + 1/2 c . H_b . c` with `H` the Hessian.
- The Drell-Yan file stores `H` directly. **The LEP file stores `Q` with
  `mu = SM + A.c + c.Q.c`, so its Hessian is `H = 2Q`.** Feeding `Q` in as
  the Hessian understates LEP curvature by a factor 2.
- Validity box: `|c_i| <= 4 pi v^2 / Lambda^2` in the NDA-graded Warsaw
  basis (0.030 at Lambda = 5 TeV).
- All worst-case prices use the monotone (backtracking) Gauss-Newton
  projection in `battery_lib._proj_chi2`; without monotonicity, stalled
  projections inflate sup-based prices.

## Reproducing the paper

Requirements: Python >= 3.11 with numpy, scipy, matplotlib.

Scripts currently read the data by absolute path (see the top of
`core/smeftgeo.py` and the individual scripts); point them at `data/` or
place the files accordingly. Then:

```
python paper/pub_figs.py            # all 7 figures
python paper/dy_reduce_realcov.py   # DY ladder + greedy reduction (real cov)
python paper/dy_reduce_end2end.py   # DY ladder (Poisson)
python paper/aic_contrast.py        # AIC vs worst-case table
python paper/lep_gates_verify.py    # LEP relations + price vs Lambda
python paper/lep_curved_v3.py       # LEP interval table
```

Each `checks/` script is standalone and prints the claim it verifies.
